# what is bootstrap  ?
  
  1. bootstrap is a framework of web technology or website designing
  2. bootstrap are used to create a responsive website
  3. responsive website means you can easily access website in any device 
  4. responsive means easily access in all device breakpoints
  5. framework provides its own structure 
  6. bootstrap provides its own **class** name to create a website or webpage structures without writing much css.

  # device break points 

    **mobile**
    1. 320px - 480px
    **tablet**
    1. 481px - 768px
    **small device**
    1. 767px - 1024px
    **large device**
    1. 1025px - 1340px
